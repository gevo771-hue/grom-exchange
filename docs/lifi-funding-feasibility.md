# Пополнение торгового баланса и прогнозов через LI.FI

Проверка 2 ноября 2026 года. Использованы публичные котировки с тестовым получателем. Подписи, перевода и проверки зачисления средств не было. Суммы и доступность ниже относятся к конкретным запросам.

| Назначение | Проверенный маршрут | Результат для GROM |
| --- | --- | --- |
| Прогнозы | 20 USDC в Arbitrum → pUSD в Polygon, получатель совпадает с торговым адресом | Получена исполнимая котировка с долей GROM 0,04 USDC. Для такого маршрута отдельный обмен USDC.e на pUSD не нужен. |
| Баланс Perps | 20 USDC в Base → USDC в HyperCore (LI.FI chain ID 1337) | Получена котировка с долей GROM 0,04 USDC. Перед включением нужно подтвердить зачисление именно на нужный торговый баланс. Сеть HyperEVM (999) для этой цели не взаимозаменяема с HyperCore. |
| Баланс Perps | 20 USDC в Arbitrum → HyperCore | Прямой маршрут hyperliquidNative вернул весь входной номинал без подтверждённой доли GROM. Для продукта с комиссией 20 bps такой маршрут следует отклонить или запросить другой. |
| Газ на новой сети | 20 и 100 USDC в Arbitrum → USDC в Base, из входной суммы 1 и 2 USDC соответственно на газ | Оба запроса с fromAmountForGas вернули 404 / 1002. Опцию следует предлагать только при наличии котировки с фактической доставкой нативного газа. LI.FI исключает Composer и contractCalls из поддержки LI.Fuel. |

Для прогнозов текущий клиент GROM использует подключённый EVM-адрес как получателя и funder. Проверять необходимо pUSD на этом адресе. Без прямой котировки резервный вариант — персональный адрес Bridge API для конкретного торгового кошелька. По его supported-assets на момент проверки минимум для USDC составил $2 в Polygon, Arbitrum и Base и $3 в Ethereum. Эти минимумы принадлежат Bridge API. Каждый прямой маршрут LI.FI имеет свои ограничения.

У текущего перевода из GROM через Bridge2 в Arbitrum минимальная сумма в интерфейсе — 5 USDC. Её нельзя переносить на все маршруты. Например, LI.FI вернул котировку на 4 USDC через другой инструмент, но этого недостаточно для подтверждения фактического зачисления. Нельзя просто отправлять средства на общий адрес Bridge2 от имени агрегатора и считать их зачисленными пользователю. Для прямого маршрута нужно связать торговый адрес, сеть, тип счёта и сумму после комиссий. Завершение подтверждается балансом площадки или записью депозита, а не одной квитанцией исходной сети.

Перед включением выбираем только маршруты с подтверждённой долей grom-exchange, сверяем минимальную получаемую сумму и назначение, показываем ожидаемое зачисление. Реальные проверки депозита, баланса позиции и аналитики комиссий выполняет владелец. Для Earn от источников Solana и TRON, в отличие от проверенных EVM-маршрутов, запросы с комиссией вернули 1011: в Partner Portal для этих сетей не настроен кошелёк комиссий.
